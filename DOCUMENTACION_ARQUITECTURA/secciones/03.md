# 03. Arquitectura del sistema

Backend monolitico por capas con paquetes application, domain e infrastructure. No es Clean Architecture estricta: application importa repositories de infrastructure y domain contiene mappings JPA. `backend/src/main/java/com/policalum/erp/application/service/AuthService.java:8` y `backend/src/main/java/com/policalum/erp/application/service/serviceImpl/ProductoServiceImpl.java:35`.

Controllers reciben DTO, servicios contienen reglas, mappers convierten entidades, repositories usan Spring Data y PostgreSQL es el driver configurado. Seguridad de filtros y metodos; frontend no constituye barrera suficiente.

Producto create abarca producto, fracciones, stock y Kardex bajo rollbackFor=Exception. `backend/src/main/java/com/policalum/erp/application/service/serviceImpl/ProductoServiceImpl.java:57`. Compra crea BORRADOR y lo recibe en la misma transaccion, no espera recepcion separada en alta nueva. `backend/src/main/java/com/policalum/erp/application/service/serviceImpl/CompraServiceImpl.java:112`.
