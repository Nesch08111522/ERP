# 23. Glosario tecnico y funcional

| Termino | Definicion contextual |
| --- | --- |
| JPA | Mapping Java de persistencia; no catalogo fisico observado |
| DTO | Contrato entrada/salida separado de entidades |
| Kardex | Movimientos de inventario y saldo resultante |
| Stock | Existencia por producto y almacen |
| Sede | Ubicacion empresarial; limites de acceso segun operacion |
| Almacen | Ubicacion de existencias ligada a sede |
| Fraccion | Factor que traduce unidades vendidas a descuento Kardex |
| CxP | Cuenta por pagar generada por compra recibida |
| Turno caja | Apertura/cierre por responsable y sede |
| Legajo | Condiciones laborales y documentos del usuario |
| Nomina | Snapshot mensual sueldo comision descuentos neto |
| TOTP | Codigo temporal verificado con secreto; no se divulga |
| JWT | Token firmado con identidad rol y version de sesion |
| Refresh | Token aleatorio cuyo hash se persiste para renovacion |
| SSE | Eventos servidor a cliente CMS/canal-web |
| CMS | Contenido e identidad/paletas administradas en ERP |
| Mapping inferido | Nombre/cardinalidad derivados del codigo, no DB comprobada |
| Implementado focal | Existencia y llamadas revisadas, sin garantia funcional runtime |
| Pendiente | Evidencia insuficiente, no equivale a inexistente |
