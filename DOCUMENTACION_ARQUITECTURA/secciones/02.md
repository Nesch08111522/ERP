# 02. Descripcion general del ERP

Policalum ERP centraliza catalogo de productos fraccionables, operaciones comerciales, compras, existencias, caja, finanzas, RRHH y contenido web. El alcance empresarial se infiere de entidades y operaciones, no de entrevistas. Usuarios administrativos y operativos, visitantes y colaboradores externos registrados como datos.

Tecnologias: Spring Boot 4.0.6 y Java 17 declarados en `backend/pom.xml:9` y `backend/pom.xml:20`. Spring Data JPA, Security, Validation, PostgreSQL driver, JJWT, MapStruct, Lombok, Caffeine, Bucket4j, Web Push, POI y OpenPDF constan en dependencias. Angular 22.1, RxJS y html5-qrcode en `frontend/package.json:13`. Versiones instaladas y runtime no comprobados.

Infraestructura activa, DNS, TLS, redes, replicas, backup y puertos efectivos: PENDIENTE DE VERIFICACION. Configuracion: [nombres y propositos](../inventarios/configuracion.md). No se muestran valores.
